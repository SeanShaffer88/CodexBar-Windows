# Roadmap

In rough order; providers are only added where a real, readable data
source exists.

- Windows field verification of the tray, DPAPI key storage, and
  OpenRouter polling; screenshots from a real run.
- Low-limit notifications from the tray.
- A small settings window (providers on/off, refresh interval, keys).
- More providers with genuine local or API sources (Gemini CLI
  credentials shipped in v0.9.0; Copilot and additional API-key
  providers from the upstream CodexBar list remain candidates).
- Per-provider icon mode, like upstream's separate status items.
