# Support

- Start with [TROUBLESHOOTING.md](TROUBLESHOOTING.md) — most problems are
  a missing local log or a missing API key, and the program's own error
  lines say which.
- `codexbar-windows --help` works fully offline and lists every command.
- Bugs and requests: open an issue on the GitHub repository with the
  output of `codexbar-windows status` (remove nothing — it contains no
  keys or personal data beyond usage totals).
